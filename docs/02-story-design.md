## 一、世界观总纲

### 世界名称
**「渊海大陆」** — 取"渊"之深邃、"海"之广阔，暗喻历史如渊、江湖如海。

### 时代背景
```
架空朝代：「渊朝」
对应历史：唐末 → 五代十国 → 宋初（约公元850-980年）
时代特征：
  ├── 中央衰落，藩镇割据（对应唐末藩镇）
  ├── 武林门派势力膨胀，左右朝局
  ├── 北方游牧民族威胁边境（对应契丹/辽）
  ├── 商业繁荣，城市兴起（对应宋代商业革命）
  ├── 科举制度完善但腐败（对应晚唐科举）
  └── 江湖与庙堂的界限模糊
```

### 架空映射规则
```

  ✅ 保留历史逻辑和事件脉络
  ✅ 保留制度、文化、社会结构
  ❌ 禁止出现真实人物姓名
  ❌ 禁止出现真实地名
  ✅ 用谐音/拆字/意境化替代

【朝代映射】

## 二、历史学习系统设计

### 核心理念
> "在江湖中经历故事，在典籍中了解真相"

```
游戏内历史知识嵌入方式：

┌──────────────────────────────────────────────────┐
│                                                  │
│  📖 典籍残卷系统                                  │
│     散落在各地的史书碎片                           │
│     收集后解锁「真实历史」对比条目                  │
│     例：游戏中"北冥之乱" → 解锁"安史之乱始末"     │
│                                                  │
│  🎓 天选试（科举小游戏）                           │
│     参加科举考试，回答历史题目                      │
│     答对获得功名/奖励                              │
│     题目涵盖：制度/人物/事件/文化                   │
│                                                  │
│  🏛️ 名胜古迹探索                                  │
│     到访历史地点触发典故讲解                        │
│     例：到"镇岳山" → 触发"封禅制度"知识            │
│                                                  │
│  🧑‍🏫 名师指点                                     │
│     NPC 对话中自然融入历史典故                      │
│     好感度越高，解锁越深的历史知识                   │
│                                                  │
│  📜 编年史（游戏内百科）                            │
│     按时间线展示架空事件 + 真实历史对照             │
│     玩家行为影响"你书写的历史"                     │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 三、主线剧情设计

### 故事主题
```
「乱世中何为侠？」

核心命题：
├── 忠义两难全 — 国家 vs 江湖 vs 个人
├── 侠之大者 — 小人物的抉择如何影响天下
├── 历史洪流 — 个人能否改变时代
└── 何为正邪 — 每个阵营都有自己的正义

情感基调：
├── 主线：苍凉史诗 + 热血成长
├── 支线：人间烟火 + 温情羁绊
├── 暗线：阴谋诡计 + 局中局
└── 终局：悲壮但留有希望
```

## 四、重要角色设计

### 主角（玩家角色）
```
默认名：「无名」（玩家可自定义）

背景：
  落渊城外小村的普通少年/少女
  父母早亡，被村中老铁匠收养
  （后揭示：你的身世与玉佩秘密息息相关）

性格（由玩家选择塑造）：
├── 正义型 → 每次选择倾向帮助弱者
├── 权谋型 → 每次选择倾向利益最大化
├── 自由型 → 每次选择倾向不受束缚
└── 混合型 → 根据情境灵活选择

成长弧线：
  无名小卒 → 初入江湖 → 声名渐起 → 一方豪杰 → 传奇/隐者
```

### 核心同伴（可招募队友）
```
⚔️ 沈若兰（女 · 剑客）
   身份：沈镇岳老将军的孙女
   性格：外冷内热，正义感强，有些固执
   武学：家传「镇岳剑法」
   剧情：寻找失踪的父亲（被叛军俘虏？已投敌？）
   招募条件：第一幕·天枢城
   好感剧情：她的父亲其实暗中是双面间谍...
   📜 历史映射：郭子仪家族后人

🗡️ 赵无痕（男 · 暗器/刺客）
   身份：江湖第一刺客组织「影楼」的叛逃者
   性格：沉默寡言，毒舌，实际很重情义
   武学：影楼暗杀术 + 独门暗器
   剧情：影楼追杀他，因为他发现了一个秘密...

## 六、游戏叙事机制

### 对话与选择系统
```
对话选项设计原则：
├── 每个对话节点 2-4 个选项
├── 选项影响：好感度 / 阵营声望 / 剧情走向
├── 没有绝对的"正确选项"，只有不同的代价
└── 部分选项需要特定条件解锁（好感度/物品/属性）

选择反馈机制：
├── 即时反馈：NPC的反应变化
├── 短期反馈：1-2个任务后的结果
├── 中期反馈：一幕结束后的格局变化
└── 长期反馈：结局走向

声望系统：
├── 朝廷声望 — 影响官场资源和天选试难度
├── 江湖声望 — 影响门派关系和NPC态度
├── 百姓声望 — 影响支线任务和物价
└── 暗网声望 — 影响地下交易和情报获取
```

### 历史知识触发方式
```
场景触发：
  进入特定地点 → 弹出"典籍残卷"提示
  例：进入天枢城皇城 → 解锁「三省六部制详解」

对话触发：
  与特定NPC交谈 → 对话中标注[典故]
  例：与萧文远谈论科举 → 解锁「唐代科举制度」

物品触发：
  拾取特定物品 → 阅读物品描述
  例：拾取「古旧通关文牒」→ 解锁「唐代通关制度」

事件触发：
  参与特定事件 → 战后总结
  例：参与赤砂关守城 → 解锁「安史之乱中的城市保卫战」

收集触发：
  收集齐一整套典籍 → 解锁完整历史专题
  例：收集齐「渊朝三帝传」三卷 → 解锁「唐玄宗/肃宗/代宗时期对比」
```

## 八、情感设计要点

### 高光时刻设计
```
必须让玩家"起鸡皮疙瘩"的场景：

1. 序章·村庄焚毁
   → 像素火焰中，你回头看燃烧的家园
   → BGM渐强，像素画面 + 光影后处理
   → "从今天起，你没有退路了"

2. 第一幕·天枢城初见
   → 城门缓缓打开，巍峨的天枢城展现在眼前
   → 像素城市 + 昼夜光影 + 繁华市井
   → 音乐从独奏笛子转为交响

3. 第二幕·真相揭露
   → 柳含章撕下伪装的瞬间
   → 所有之前看似善意的举动回放
   → "你从一开始就是棋子"

4. 第三幕·同伴抉择
   → 你做出了与同伴相反的选择
   → 他在雨中转身离去（或留下）
   → 像素雨滴 + 感伤BGM

5. 终章·最终决战前夜
   → 营火旁，所有同伴逐一与你对话
   → 每个人回忆一路走来的经历
   → 然后天亮了
```

### 幽默调剂（避免全程沉重）
```
搞笑元素：
├── 萧文远的冷吐槽和酸诗
├── 苏青禾的路痴事件（走到敌营还以为到了药店）
├── 赵无痕被小孩认出来时的社恐反应
├── 食物系统的奇葩料理（"这碗面里...有毒？" "是花椒啦！"）
├── NPC的日常对话彩蛋
└── 像素表情包系统（Q版大头弹出的夸张表情）
```
