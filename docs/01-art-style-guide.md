## 二、像素规格定义

### 基础参数
```
分辨率目标：1920×1080（PC）/ 自适应缩放
像素密度：角色 32×32 ~ 64×64
         场景物件 16×16 ~ 128×128
         Tile（瓦片）16×16 或 32×32
像素完美渲染：开启（Pixel Perfect Camera）
抗锯齿：关闭（保持锐利像素边缘）
缩放过滤：Point/Nearest（禁止双线性过滤）
```

### 画面呈现模式
```
推荐方案：HD-2D 混合渲染（像素精灵 + 3D场景 + 光影后处理）

┌──────────────────────────────────────────────┐
│  渲染层次（从后到前）                          │
│                                              │
│  Layer 5: 后处理（景深、光晕、色彩校正）        │
│  Layer 4: 粒子特效（水墨飞溅、火花、烟雾）      │
│  Layer 3: 3D 环境光照 + 动态阴影              │
│  Layer 2: 像素精灵（角色、NPC、怪物）           │
│  Layer 1: 3D 场景地形 + 建筑 + 植被            │
│  Layer 0: 天空盒 / 远景                       │
└──────────────────────────────────────────────┘
```

### 角色动画帧表
```
基础动画（所有角色）：
├── 待机 (Idle)         4-6帧   循环
├── 行走 (Walk)         6-8帧   循环   ← 4方向
├── 跑步 (Run)          6-8帧   循环   ← 4方向
└── 受击 (Hurt)         3-4帧   单次

战斗动画（主角/重要NPC）：
├── 攻击1 (Attack1)     4-6帧   单次   ← 普通攻击
├── 攻击2 (Attack2)     6-8帧   单次   ← 重击/技能
├── 技能 (Skill)        6-10帧  单次   ← 武学绝招
├── 防御 (Guard)        2-3帧   保持
├── 闪避 (Dodge)        4-6帧   单次
├── 倒地 (Down)         4帧     单次
└── 死亡 (Death)        4-6帧   单次

交互动画：
├── 对话 (Talk)         2-4帧   循环
├── 拾取 (Pickup)       3帧     单次
├── 攀爬 (Climb)        4-6帧   循环
├── 轻功/跳跃 (Jump)    4-6帧   单次
└── 坐下 (Sit)          2帧     保持

表情系统（对话框立绘/像素气泡）：
├── 默认 / 开心 / 生气 / 悲伤 / 惊讶
├── 害羞 / 得意 / 思考 / 疑惑 / 省略号
└── Q版大头表情 16×16
```

### 角色设计原则
```
1. 轮廓辨识度优先（silhouette readable）
   → 在缩放到实际游戏尺寸时，仅靠剪影就能分辨角色类型
   
2. 武器/配饰夸张化
   → 剑客的剑比实际比例大 1.5 倍
   → 书生的书卷在视觉上更突出
   
3. 配色区分职业
   剑客 → 白/蓝（清冷孤傲）
   拳师 → 红/橙（热血刚猛）
   暗器 → 黑/紫（神秘莫测）
   医者 → 绿/白（仁心济世）
   书生 → 棕/黄（儒雅内敛）
   异人 → 紫/金（非俗之人）
   
4. 像素艺术技巧
   → 选择性描边（Selective Outlining）：仅在下边缘加深
   → 抖动渐变（Dithering）：用棋盘格图案模拟半透明
   → 像素簇（Pixel Clusters）：避免孤立的单一像素点
   → 子像素动画：微微偏移1-2px实现呼吸感
```


## 八、Unity 技术实现要点

### 渲染管线
```
推荐：URP (Universal Render Pipeline)

关键组件：
├── Pixel Perfect Camera  →  确保像素锐利
├── 2D Lights             →  法线贴图+光影
├── Post Processing       →  景深、泛光、色彩校正
├── Cinemachine           →  镜头控制
└── Tilemap System        →  场景搭建
```

### Shader 方向
```
核心 Shader：
├── 像素精灵 Shader     →  支持法线贴图的2D光影
├── 水面 Shader         →  像素风格的波纹和倒影
├── 场景环境 Shader     →  HD-2D 风格的景深和光照
└── 后处理 Shader       →  色彩量化 + 像素化边缘
```
