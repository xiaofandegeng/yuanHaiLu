# 参考板 v1

用途：为 32×32 角色母版和烟柳镇 16×16 Tile 模块提供轮廓、材质与配色方向，不直接作为 Unity Sprite 或 Tileset 使用。

生成方式：OpenAI 内置 imagegen（2026-08-13）。

保留特征：

- 男、女剑客使用白、蓝、墨色服装，靠发型、袖型和下摆轮廓区分。
- 烟柳镇使用白墙、深灰青瓦、木构、石桥、柳树、荷花、河道、码头和乌篷船。
- 朱砂红仅作灯笼等视觉焦点，不大面积铺色。

降阶要求：

- 角色必须重新绘制为 32×32 整数像素模块，不能直接缩放参考板人物。
- Tile 必须重新绘制为 16×16 无缝模块，建筑地标使用底部中心锚点的大精灵。
- 禁止抗锯齿、半透明轮廓和孤立噪点。
