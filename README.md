# 渊海录 (YuanHaiLu) — Unity 6 像素武侠RPG

> 🎮 Demo版本 | Unity 6 (6000.4.10f1) | 2D Pixel Art | Apple Silicon

## ⚡ 快速开始

### 1. 打开项目
```
Unity Hub → Open → 选择此文件夹（yuanHaiLu）
```

### 2. 生成场景
等 Unity 编译完成后（可能需要1-2分钟），执行：

```
菜单栏 → Tools → 渊海录 → 生成主菜单场景
菜单栏 → Tools → 渊海录 → 生成Demo场景
```

### 3. 配置 Build Settings
```
File → Build Settings
→ 添加 MainMenu (index 0)
→ 添加 Demo_YanLiuTown (index 1)
```

### 4. 运行！
双击 `MainMenu` 场景 → 按 **Play**

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| J | 攻击（可连击3次） |
| K | 交互（对话/拾取） |
| Left Shift | 冲刺 |
| Tab | 背包 |
| Q | 任务日志 |
| ESC | 暂停菜单 |
| Space | 对话中推进文本 |

## 📂 项目结构

```
Assets/
├── Scripts/          ← 所有C#代码
│   ├── Core/         游戏核心（状态机/摄像机/场景引导）
│   ├── Character/    角色系统（玩家/NPC/敌人/属性）
│   ├── Map/          地图系统（瓦片/传送/事件/破坏物）
│   ├── Dialogue/     对话系统
│   ├── Effects/      特效系统（剑气/伤害数字/闪烁）
│   ├── System/       系统管理（背包/任务/存档/音频/商店/昼夜）
│   ├── UI/           界面（HUD/菜单/背包UI/任务UI/暂停）
│   ├── Combat/       （预留）
│   └── Editor/       编辑器工具（场景生成/精灵配置）
├── Resources/        ← 运行时加载的资源
│   ├── Items/        物品定义（ScriptableObject）
│   ├── Quests/       任务定义（ScriptableObject）
│   ├── Audio/BGM/    背景音乐
│   └── Audio/SFX/    音效
├── Scenes/           ← 场景文件（由生成器创建）
├── Sprites/          ← 精灵资源
├── Prefabs/          ← 预制体
├── Animations/       ← 动画
└── Fonts/            ← 字体
```

## 🎯 Demo内容

### 场景：烟柳镇
- 30x20 格地面（草地）
- 4面围墙 + 3座建筑（客栈/商铺/药铺）
- 5棵装饰树 + 水井 + 指示牌

### 角色
- **凌霜**（玩家）：蓝衣侠客，HP100/MP50，攻击15
- **掌柜老赵**：客栈老板，提供主线情报
- **苏婉清**：药铺少女，玉佩之谜相关
- **钓鱼翁**：隐世高手，暗示可学轻功
- **山贼×3**：普通敌人，会巡逻追击
- **路匪×1**：稍强的敌人

### 系统演示
- ✅ 8方向移动 + 冲刺
- ✅ 3连击战斗 + 暴击 + 剑气特效
- ✅ NPC对话（3个NPC各有4句台词）
- ✅ 敌人AI（巡逻→追击→攻击→脱离）
- ✅ 可破坏木箱（掉落金币/物品）
- ✅ 波次战斗事件（BOSS战触发器）
- ✅ HUD显示
- ✅ 暂停菜单（ESC）
- ✅ 存档系统
